# 河南理工大学：校园地图、标志建筑与标志事件来源索引

核验日期：2026-11-03。以下是研究整理，不是学校官方出版物。原始图片另由素材目录收录；此文件不声称已经下载所有链接。页面公开可访问不等于作品获准自由再发布，特别是公开 GitHub 仓库、商业使用或改编前，应核查授权。

## 1. 校园地图与校区边界

- **南、北校区官方平面图（2025年6月版）**：党委宣传部页面发布于2025-09-05，提供“南.jpg”“北.jpg”两个附件。优先使用这组新版地图，不把旧新闻所述“三校区”当作当前地图口径。来源：https://xcb.hpu.edu.cn/info/1007/2435.htm
- 官网当前页脚地址：南校区为焦作市世纪路2001号；北校区为焦作市解放中路142号。来源：https://www.hpu.edu.cn/xxgk/lsyg.htm
- 历史材料中存在“南北西三个校区”表述：2019-08-31的明德广场文化长廊报道展示了当年的三校区平面图与鸟瞰图。它可作历史素材，不应据此把旧西校区地图标为当前最新版。来源：https://news.hpu.edu.cn/info/1003/3847.htm

## 2. 地标建筑与景观选题

### 北校区：历史建筑

1. **焦作工学院工程馆**：校方115周年主题标识说明明确把工程馆作为学校地标提炼进标识，适合代表百年校史。来源：https://www.hpu.edu.cn/info/1104/5437.htm
2. **焦作煤矿工人大罢工指挥部旧址**：校内红色历史地标。2022年报道说明其为省级文物保护单位、河南省首批不可移动革命文物。来源：https://news.hpu.edu.cn/info/1003/2298.htm
3. **英福公司总办事处旧址**：与工程馆、罢工指挥部旧址一起列入2025年北校区文物建筑安全检查报道。三处在该报道中称为省级文物保护建筑；不要升级称为“全国重点文物保护单位”。来源（2025-02-24）：https://jiwei.hpu.edu.cn/info/1008/1849.htm

### 南校区：现代校园与文化景观

- **东门、南门、西门、明德楼、世纪广场、教学楼、图书馆、体育场馆**：校方人文景观报道列为现代校园代表。该文同时列出馨月湖、荷花湖、清涟湖等景观。来源（2019-08-31）：https://news.hpu.edu.cn/info/1003/3847.htm
- **第二图书馆**：位于南校区东北部、清涟湖北端，2020年12月投入使用。
- **体育馆**：东大门内北侧，2014年7月投用。
- **国家重点实验室大楼**：南大门内西侧，2020年1月投用。
- **历史文化园**：三号教学楼南侧，2019年110周年校庆前投入使用；“理工赋”广场是其中的代表景观。
- 上述四项建设时间及位置共同来源（配有图片）：https://www.hpu.edu.cn/info/1095/3843.htm
- **清涟湖及四座桥**：2014年建成，连接春秋大道与第二图书馆；由南至北为致远桥、笃行桥、乐学桥、立德桥。湖名纪念教育家张清涟。基建处独立图文来源（2024-07-10）：https://www6.hpu.edu.cn/jjc/info/1031/1158.htm
- **校史馆**：2022年官方新闻明确位于南校区。不能把校史馆与北校区历史建筑混为同一地点。来源：https://news.hpu.edu.cn/info/1003/2298.htm

### 与校园遗址相关的地方历史事件

- 1925年7月至1926年3月，焦作煤矿工人大罢工；1926-03-06举行复工仪式。国家能源局（2021-12-02）：https://www.nea.gov.cn/2021-12/02/c_1310346862.htm
- 这属于与校内遗址有关的地方工运史，不能简单改称为“河南理工大学举办的活动”，也不要把其他矿区纪念馆照片标成校内旧址。

## 4. 必须保留的史料差异
