# 学生主角真人写实头像 v1

- 文件：`student-portrait-realistic-v1.png`
- 用途：视频制作的人物参考图，正面头肩构图。
- 规格：1086 × 1448，PNG，RGB，浅灰背景。
- 日期：2026-11-09。
- 角色：沿用游戏中行走的虚构男大学生，保留黑色微乱短发、深灰绿连帽外套、白色 T 恤和黑色背包肩带。

- 生成方式：AI 图像生成，以原游戏行走精灵为设计参考转为真人摄影质感。不是现实学生照片，也不对应任何指定真实人物。
- 提示词：见 [generation-prompt.txt](generation-prompt.txt)。

## 视频使用建议

上传本图作为学生主角的角色参考，后续镜头保持同一张脸、发型和服装。浅灰背景用于清楚呈现面部，不是游戏场景。后续图生视频会产生一定身份偏差，输出仍需逐镜头检查。

本目录仅新增视频用素材，不替换行走精灵，也不修改已归档试玩版本。
