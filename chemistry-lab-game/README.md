# 化学实验游戏

使用 Godot 4 标准版（GDScript），Compatibility 渲染器。

## 开发

1. 安装 Godot 4.3 或更新的 Godot 4 稳定版：https://godotengine.org/download/
2. 下载或克隆此仓库。
3. 在 Godot 项目管理器中导入本目录的 project.godot。
4. 按 F6 运行当前场景或 F5 运行项目。

命令行启动：`godot --path chemistry-lab-game --editor`

无界面导入检查：`godot --headless --path chemistry-lab-game --editor --quit`

本目录包含初始标题场景，实验玩法尚未实现。当前语音执行环境不支持运行 shell，因此尚未安装或运行验证 Godot。
