## 运行

无需构建或安装前端依赖。在本目录启动静态 HTTP 服务：

```sh
python3 -m http.server 8000 --directory dist
```

然后访问 <http://localhost:8000>。不能直接以 `file://` 打开，因为程序通过 `fetch` 读取道路和动画数据。手机测试时，可将 `dist/` 部署到有权使用的 HTTPS 静态站点。

## 已包含的试玩内容

- 手机虚拟摇杆、慢走、地图缩放、菜单、路网显示和角色四向行走动画。
- 键盘 WASD / 方向键移动，E / 空格互动，Esc 返回。
- 校园 → 化工学院大厅 → 实验室 → 实验台占位交互。
- 沿参考地图绘制的可通行区域和基础碰撞限制。

## 原型边界与已知问题

- 地理位置、真实入口、现实道路状况和室内布局仍待核实。建筑内部是玩法占位。
- 当前没有真实实验规则、计算模型、测量结果、完整剧情或教师角色。
- 道路为依据参考图提取和人工排除的像素通行区，不是道路测绘、实景导航或完整的校园通行保证。
- v6 的道路加载失败分支未设置 `roadError`，所以真实网络失败时错误提示可能被覆盖，重试按钮不保证出现。本快照保留已发布行为，没有混入修复。
- 已通过 JavaScript 语法检查及 `node test-interactions.cjs` 的模拟交互测试。该测试不等同于完整真机、浏览器或断网测试。

## 文件与复核

- `dist/`：可直接部署的网页、脚本、地图、人物精灵和道路数据。
- `test-interactions.cjs`：v6 原有 Node.js 模拟交互测试。
- `extract-roads.py`：v6 原有道路提取脚本，需要 Pillow、NumPy 和 SciPy。它会重写 `dist/walkable.json`，预览输出路径仍是原环境的绝对路径；仅运行试玩时不需要执行。
- `version.json`：源版本、文件大小、SHA-256 与 Git blob SHA-1，便于核验。
- `ATTRIBUTION.md`：素材来源、版权及使用限制。
