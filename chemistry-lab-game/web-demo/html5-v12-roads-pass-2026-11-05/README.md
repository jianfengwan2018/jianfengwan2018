保存日期：2026-11-05。

**版本标记：道路已走通（用户试玩确认）。** 本目录保存用户实际试玩后要求归档的程序版本，包含道路、音乐和天气。该表述记录游戏中的试玩结论，不代表对现实校园所有道路的测绘或安全保证。

## 本地运行

无需构建或安装前端依赖，在本目录运行：

```sh
python3 -m http.server 8000 --directory dist
```

浏览器访问 <http://localhost:8000>。不要直接用 `file://` 打开，因为程序需要读取道路与精灵帧数据。天气功能需要连接 Open-Meteo，离线时回退默认画面。

## 此版本内容

- 根据参考图修补校园可通行道路，包含路线引导和基础碰撞限制。
- 手机虚拟摇杆、慢走、地图缩放、路网显示、四向人物动画。
- 校园 → 化工学院大厅 → 实验室 → 实验台占位交互。
- 《春日回声·2050》96 秒循环背景音乐，提供 Ogg 和 M4A；点击开启，离开页面暂停。
- 固定校园近似坐标的天气显示与天气效果，不申请设备定位；天气源是模型数据，不是校园现场观测。
- 键盘 WASD / 方向键移动，E / 空格互动，Esc 返回。

## 核验

道路数据共 218175 个可走像素，组成一个连通组件。122 个方向路段以及池塘绕环、附属小学西侧道路往返测试通过。交互、音乐和天气模拟测试通过。完整记录和旧测试的误报说明见 [QA.md](QA.md)。

这不是所有设备、所有输入组合的穷尽验证。建筑内部仍是玩法占位，不含真实实验规则、测量数据、完整剧情或教师角色。

## 配套文件

- `dist/`：可直接部署的运行文件。
- `road-corridors.json`：道路修补中心线与宽度。
- `extract-roads.py`：原道路提取脚本，需要 Pillow、NumPy 和 SciPy；会重写道路数据，其预览输出仍使用原环境绝对路径。运行游戏无需执行它。
- `test-*.cjs`：原版本测试脚本。
- `version.json`：版本与文件哈希清单。
- [ATTRIBUTION.md](ATTRIBUTION.md)：地图、音乐、人物和天气数据来源与限制。
